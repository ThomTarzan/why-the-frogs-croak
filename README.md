# Чому жабки весело кумкають

En digital barnebok, med teksten på ukrainsk, engelsk og norsk. Illustrasjonene og historien er brukt med forfatterens tillatelse.

Bla nedover, eller bruk pilene, for å gå til neste oppslag. Øverst til høyre bytter du språk: УК, EN eller NO. På første side kan barnet trykke på frosken, så hopper den.

## Kjør lokalt

```bash
npm install
npm run dev
```

Åpne adressen som Vite skriver ut. Utviklingsserveren i dette prosjektet bruker port 43123.

```bash
npm run build
npm run preview
```
